# The AI That Nobody Can Find: storyboard and design system

Timecodes come from the synthesized narration (`src/timeline.json`, phrase-level cues in `src/cues.json`), so every visual event is keyed to a spoken phrase rather than to a hand-typed time.

## Design system

| Token | Value | Use |
|---|---|---|
| Graphite | `#050608` → `#0d1014` | negative space, every background |
| Paper | `#e9e4da` | all type, neutral objects |
| Steel | `#8ea2b4` | infrastructure, legitimate computing |
| Amber | `#f0a14a` | **only** the hypothetical system (one meaning, never decoration) |
| Rust | `#c4553b` | malware / botnets only |

* Type: **Inter Display** (titles, tracked caps labels), **FreeSerif italic** (questions, the voice of the film), **DejaVu Sans Mono** (data, logs, measurements).
* Labels are small, tracked caps with a hairline rule; never more than one label block on screen at once.
* Every claim on screen carries a status tag: `EXISTS TODAY` · `ACTIVE RESEARCH` · `SPECULATIVE`.
* Camera: long eased moves (≥ 3 s), no handheld shake, no random cuts. Scale changes are the storytelling device: phone → chip → field of millions; Earth → abstract structure; phone → room → city → planet.
* The one recurring visual: a tiny amber glyph (a tetrahedron inside a ring) is "the process". It is the same object in every act.
