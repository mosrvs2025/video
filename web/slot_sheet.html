Swap steps

  1. Generate each clip as 3:4 portrait (e.g. 1080×1440), at least the slot length. Name them clip_1.mp4 … clip_8.mp4. You can skip slots: an empty slot just shows the green key over black, so use the clean video if you skip any.
  2. Editor way (CapCut / Premiere / DaVinci / Final Cut): put the keyed video on the top track. Put each clip on the track under it, starting at the slot's start time, scaled to fill a 720×960 box centred horizontally with its top at y=105 (in a 1080×1920 timeline). On the keyed video add Chroma key / Color key on pure green #00ff00, similarity ≈ 30 %, edge feather ≈ 10 %. The brass frame stays; only the green disappears.
  3. Command-line way: python3 pipeline/swap.py songs/price_of_free clips/ out.mp4 does exactly the above with ffmpeg (clips named clip_N.mp4).
  4. Check the labeled version first: each window shows its slot number, time range and direction, so you can see where each clip lands.
